# 🗺️ 后续更新计划

根 README 只保留摘要；本文跟踪下一阶段事项。完成后请勾选并写入 [CHANGELOG.md](./CHANGELOG.md)。

## 原则

1. **当前已有**：基本博客展示（静态 Markdown + Cloudflare Pages）
2. **尚未有**：管理页（写文 / 管文）、评论上线、C# 后端
